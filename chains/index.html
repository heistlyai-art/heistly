File 07 — Chains

Where a note can land.

Five chains are on the brief. Robinhood Chain is home, and it is where $HEIST will be issued. The other four are escape routes. None of these lanes is a live bridge on this website.

Robinhood Chain

Home · $HEIST

The vault’s first desk. Deposits, getaways, and the token’s contract — when that contract is real — belong here first.

Base

An escape lane. A note can be delivered on Base without your wallet signing a public bridge transfer.

Arbitrum

Same rule as Base. The route is part of the brief. There is no live arrival time to quote.

BNB Chain

A further street. Use it when the payment has to exist there. The sender on that delivery should still not be your wallet.

Solana

A different rail, written on the same sheet. An escape onto Solana is a delivery on Solana, not a transfer your wallet signs in public.
