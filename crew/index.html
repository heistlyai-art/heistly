File 05 — Crew API

Let an agent pay without borrowing your wallet.

Crew API is the door for scripts and AI agents. They can ask the desk to seal, switch, escape, or send. The note and the proof stay on a machine you choose. The agent does not receive a seed. This door is drawn, not open.

Two doors

A CLI for scripts. MCP for agents.

CLI

heist

A command line for jobs you can read before they run. Seal a note. Pay an address. Ask for a switch. Nothing here is installed yet.

MCP

Tools, not keys

An assistant calls a named tool. The tool asks the desk. The assistant never sees the secret inside the note, and it never sees a seed phrase.

Driver

Same relayer

An agent does not get a special trail. A getaway it requests is still posted by the Driver, and your wallet is still absent from that send.

Not a console

No commands are published yet.

A CLI and an MCP surface are part of the plan. The names are not final, nothing is installed, and this page does not include a sample that could be mistaken for a working tool.

What an agent will not receive

A seed phrase, a private key, or a copy of the note. When the API exists, a script will be able to ask for a seal, a getaway, a switch, or an escape. It will not be able to ask from this website.

MCP names on the brief

Tools an agent would call.

Working names for the plan. No schema is published, and none of these resolve.

heist.note.seal
Ask to seal ETH, USDC, or USDG into a note that stays on the caller’s machine.
heist.getaway.pay
Ask the Driver to pay an address. The tool takes a destination and an amount, not a seed.
heist.switch.quote
Ask what a trade inside the vault would look like. A quote is not a fill, and the app is not quoting yet.
heist.escape.route
Ask for a private bridge onto Robinhood Chain, Base, Arbitrum, BNB Chain, or Solana.

Not live

No agent can spend from this page.

When the API opens, the docs will carry the real commands. Until then, treat any package or endpoint that claims to be Heistly as untrusted.
